CAREPOINT HOSPITAL MANAGEMENT SYSTEM - DBMS MINI PROJECT

FILES
- index.html : Working website demo (patients, doctors, appointments, billing)
- schema.sql : MySQL database table setup and sample records

UPLOAD TO GITHUB AND GET A WEBSITE LINK
1. Sign in at https://github.com
2. Create a new PUBLIC repository named Hospital-Management-System.
3. Choose Add file > Upload files.
4. Upload index.html (and schema.sql if your teacher wants the database script).
5. Click Commit changes.
6. Open repository Settings > Pages.
7. Under Build and deployment, choose Deploy from a branch.
8. Select branch main and folder /(root), then Save.
9. Wait a minute and refresh the Pages section. GitHub will show your public website URL.

DEMO STORAGE NOTE
The website allows adding patients, doctors, appointments, and bills. Records are saved in the browser's local storage on the device/browser used to enter them. This is a frontend demonstration; it is NOT connected to a live shared MySQL database. Different users/devices will not automatically see each other's records. The schema.sql file is provided for the database part of the DBMS project.

Use fictional patient information for demonstration only.
